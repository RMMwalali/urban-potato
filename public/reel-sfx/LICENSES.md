# Sound effect licences

All output files are in this folder as `.mp3` (libmp3lame -q:a 4) and `.ogg` (libvorbis -q:a 4), mono, 44.1 kHz,
leading/trailing silence trimmed, 2 ms fade-in / short fade-out, peak normalised to about -3 dBFS.

**Every file is CC0 / public domain. No attribution is legally required for any of them, and there are no CC-BY files in this set.**
Credit lines are listed anyway in case you want to give voluntary credit.

Licences were checked on each source page on 2026-11-17 (OpenGameArt licence field, Kenney asset page + bundled `License.txt`,
Wikimedia Commons file-description wikitext).

- CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/

("Sound effect made by jingling coins") with the CC0 mechanical bell recording. Mechanical registers used the same kind of bell.
